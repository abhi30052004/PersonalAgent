# ATLAS — AI Research & Knowledge Agent

## Overview
ATLAS is an AI research and knowledge agent designed to let users collect documents and web resources, retrieve relevant information, and interact with their knowledge through cited AI responses.

## Core Features
- Upload and process PDF, DOCX, TXT, CSV, XLSX, and PPTX files.
- Process web URLs as knowledge sources.
- Retrieval-augmented generation (RAG).
- Cited chat responses.
- Artifact Studio for generated content.
- Report and presentation generation.
- Knowledge and usage analytics.
- Authentication and user management.

ATLAS was an important project for learning RAG, LLM application architecture, document processing, retrieval, backend APIs, and AI-assisted research workflows.
