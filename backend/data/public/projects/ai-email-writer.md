# AI Email Writer

## Overview

An AI-powered application that helps users generate professional emails from their requirements.

## Features

- AI-assisted email generation.
- Professional email writing.
- Tone and content customization.
- Faster email drafting.
- Prompt-based content generation.

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- OpenAI API

## Related Learning

Built while learning LLM Engineering, RAG, and AI application development.

## Future Work

- Add more tone and style options.
- Add email history and saved drafts.
- Improve AI-generated content quality.
- Add Gmail/Outlook integration.
