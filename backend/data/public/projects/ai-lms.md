# AI Learning Management Platform

## Overview

An AI-powered learning management platform with role-based access and AI-assisted learning features.

## Features

- Student, Teacher, and Admin roles.
- Firebase authentication and role-based access control.
- AI tutor capabilities.
- RAG-based learning from PDFs and YouTube content.
- ChromaDB-based knowledge retrieval.
- Multilingual learning support in English, Hindi, and Bengali.

## Tech Stack

- React
- Firebase
- OpenAI
- RAG
- ChromaDB

## Future Work

- Improve AI tutor capabilities.
- Add more learning resources.
- Improve personalized learning recommendations.
- Add progress tracking and analytics.
