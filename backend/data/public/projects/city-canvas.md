# City Canvas

City Canvas is a full-stack web application built during the FastAPI, TypeScript, and data-focused learning phase.

- Modern web application interface.
- Backend API development.
- TypeScript-based frontend.
- Structured data handling.
- Data visualization.
- API-driven application architecture.
